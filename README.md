# Airline Customer Behaviour Analysis

**Tools:** Python, Pandas, NumPy, Power BI  
**Dataset:** 130,000+ passenger records  

## Objective  
Analysed passenger data to identify key satisfaction drivers, loyalty patterns, and service improvement areas.

## Key Steps  
- Data Cleaning & Transformation  
- Exploratory Data Analysis (EDA)  
- Interactive Power BI Dashboard with KPIs (Customer Satisfaction Score, Delay Impact, Loyalty Indicators)  

## Key Findings  
- Identified major satisfaction drop-off points across service categories  
- Uncovered loyalty patterns across frequent vs infrequent flyers  
- Reduced manual reporting effort by 40% through automated dashboards  

## Files  
- `raw_dataset.csv` — Original uncleaned data  
- `cleaned_dataset.csv` — Processed & transformed data  
- `airline_analysis.ipynb` — Python notebook (Cleaning + EDA)  
- `dashboard.pbix` — Power BI dashboard
